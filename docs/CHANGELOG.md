# Changelog

## 1.0.0 (2026-11-12)

First version.

- Reads a lead sheet from a file or a published Google Sheet CSV.
- Checks: stuck new leads, cold follow-ups, overdue and upcoming calls, booking-rate and volume drops with the source that explains them, data hygiene.
- Daily digest to Telegram; warning message when the sheet can't be read.
- GitHub Actions: daily digest and test run.
- 52 tests; bug-injection script.
- Synthetic demo data and generator.
- SOP for alert response, system map, AI workflow notes.
